# 第二章逐日任务拆解（D3–D6 基线版）

编制：2026-10-23｜依据当天工程核查（见 `docs/第二章进度核查与D2任务卡_20261023.md`）
用法：**这是基线，不是铁轨。** 每天开工前按昨天的实际交付重切一次；没交的项不许默认顺延，要么当天补、要么当场砍。

---

## 零、先说一个必须知道的数

程序从 D2 起算到 D6，一共只有 **5 天 × 2 小时 = 10 小时**。
而按现有缺口数，程序侧还压着 **16 项接入**（判定模块、秋千、图书馆路口、教室四调查、日记选择、宵禁选路、End5、馆内三调查、媒介选择、净化、背刺、回溯物品回滚、闪避、失败重试、两次交付、End6）。

按最乐观 —— **每项 20 分钟、一次接对、不调试** —— 也要 5.3 小时。真实接入包含找位置、试跑、修错、等文案定稿，实际通常翻倍。**16 项塞不进 10 小时。**

所以这份拆解做了两件事，你必须知道：

1. **把 D4 的"主线首通到 End6"改判为"到背刺为止"。** 原计划 D4 首通、D7–D9 润色，是按 D1 已经交出判定原型算的；原型没落成，等于整条链往后挪了一天。硬按原表走，D7 会变成"还在补主线"，润色三天直接消失。
2. **把能搬的活搬到文案和内容整合身上。** 计划里"文案按模板录简单调查"这条目前一次都没执行过 —— 今天必须真的开始，否则程序永远在打字。

如果你更愿意保住 D4 首通，那就得砍内容（见第七节），而不是让程序加班。

## 一、依赖关系（决定先后，不能乱排）

```
判定模块 ──→ 秋千接救援 ──→ 闪避（复用同一套）
图书馆回程口 ──→ 馆内三调查 ──→ 媒介选择 ──→ 净化 ──→ 背刺 ──→ 回溯（物品回滚）──→ 交付 ──→ End6
教室四调查 ────────────┘（日记是媒介选择的钥匙，必须先有）
        └──→ 日记理解选择 ──→ 宵禁选路 ──→ End5
```

三条硬约束：

- **日记没接，图书馆的媒介选择就没得选**（日记是唯一正确媒介）。所以教室调查必须早于馆内选择。
- **回溯的物品回滚必须先定表**（哪些保留、哪些收回），否则接完回溯会出现"结晶拿两次"或"日记被吞掉、再也救不了猫"。
- **结局表没加之前，End5 / End6 只能拿临时 ID 顶着**，别等最后统一。

## 七、砍的顺序（哪天落后就按这个砍，别现场商量）

1. 界面动效、宽松模式、按钮多余状态
2. 追逐第二段（借书架摆脱 C 的自由寻路）→ 改成一屏演出
3. 每段调查的独立音效 → 共用一条
4. 背刺 CG → 现有场景 + 立绘
5. 日记三页 → 两页（合并"搬离"与"等待"）
6. 闪避独立关 → 直接用选项代替

**永远不砍**：判定→失败→重试的完整回环；图书馆进出闭环；日记为什么能救猫；回溯后能主动改变结果；两次交付 + End6。

## 八、每天开工前的三个问题（10 分钟站会，别问多）

1. 昨天你交的东西，**在游戏里点得到吗**？（交文件 ≠ 交功能）
2. 今天这件事，卡住的**前置条件**在谁手上？
3. 今天结束前，**别人能自己验证**你的交付吗？

回答不了第二问的，当天先做能做的部分，并当场把阻塞写进群里 —— 不要闷头猜。
