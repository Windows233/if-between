# 分支职责与整合规则

2026-10-23 调整：地图编辑器作为可选 Godot 编辑器插件随 `main` 提供；它不进入游戏运行时或导出包。

| 分支 | 职责 | 不应只留在这里的内容 |
| --- | --- | --- |
| `main` | 可运行游戏、地图 JSON、美术与音频、剧情、公共数据结构、物理与寻路、数据检查、游戏测试，以及 `addons/if_map_editor/` 地图编辑器插件与专用测试 | 无 |

插件由 `project.godot` 启用，Godot 编辑器可从顶部「IF 场景」进入；项目源码在 `main` 中即可使用。`export_presets.cfg` 排除 `addons/*`，所以地图编辑器不会进入游戏发行包。插件测试单独运行，不由游戏主测试入口预加载。物件局部碰撞、局部交互范围、自动遮挡与地图校验属于游戏数据协议，保留在 `main`。

## 日常操作

1. 改游戏、地图或素材，在 `main` 上工作。地图和素材文件由地图编辑器保存，正式内容照常进入 `main`。
2. 地图编辑器插件代码也随 `main` 维护；不设长期专属编辑器分支。其他编辑器改动遵守通用分支与验证流程。
3. 游戏测试运行 `tests/run_tests.gd`；插件测试另运行 `tests/run_map_editor_tests.gd`、编辑器探针与试走检查。
4. 只推明确的目标分支。清理其他分支之前，检查祖先关系、独有提交和最终文件内容，不能靠名字判断是否过期。

当前 `addons/godot_mcp/` 是既有开发连接工具，本次只抽离 IF 地图编辑插件，未改动该连接工具。
