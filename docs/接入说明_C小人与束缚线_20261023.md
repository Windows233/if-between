## 3. 怎么把线放到C身上

线是场景里的装饰效果，跟随C的脚底锚点，不放到屏幕固定角落，也不挂到轨道上。

1. 先用C的`down1.png`正面站姿校准；线画布与角色画布共用脚底中点，不按各张图片的可见像素包围盒重新居中。
2. C单帧是64×64，线是256×256。两者源尺寸差4倍，**不能套同一个缩放值**。
3. 按现有C的32像素画布高度，C单帧约缩放0.5，线层约缩放0.125，即都覆盖32×32的显示画布。先按该比例和相同脚底对齐，再以实机躯干部位微调；它是对位起点，不是已经实测的最终参数。
4. 三张状态切换时位置、比例和锚点保持完全一致；不逐张自动裁剪，不让剩余线跳动。
5. 线放在C前方，不能创建额外碰撞、调查框，也不能遮住主角的关键提示和对话。
6. 当前面板有较深的全屏遮罩。小游戏打开时必须还能看清C和线的变化；如遮罩盖得过暗，由程序调整其透明度或布局，不能把“线已经存在但看不见”当作完成。
