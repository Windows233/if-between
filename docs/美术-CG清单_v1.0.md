## 四、规格与验收（每张都按这个查）

- **尺寸**：1672×941。合照除外（800×600 左右）。
- **安全区**：下方约 1/4 不放关键信息，那里会被对话框和字幕压住。
- **画风**：与 `end1平静即死亡.png` 并排看，要像同一个人画的 —— 笔触、暗部、光色一致。
- **人物一致性**：主角红围巾、发色、外套固定；C 白发、服装与 `art/npc/c` 小人一致；C 的正脸在同一天里做的几张要对得上。
- **恐怖感的度**：靠压迫感、空间错位、光线，不靠血浆和满屏红光。
- **验收动作**：导出成 1672×941 的 PNG，放进 `art/cg/`，在游戏里实际走到那个节点看一次，确认不被对话框盖住脸。
