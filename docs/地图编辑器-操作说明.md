## 一、打开

1. 用 Godot 打开这个项目（版本 4.7.2）。
2. 插件已经在 `project.godot` 里启用了。打开后**底部**会出现一块面板，
   标题旁边写着 `IF 地图编辑器`。
3. 没看到面板：`项目 → 项目设置 → 插件`，把 `IF 地图编辑器` 勾上，
   或点一下别的面板标签再回来。

面板一打开就会载入地图列表里的第一张图。

## 二、面板长什么样

```
地图：[gatehouse ▾]  [重新载入（丢弃改动）]  [保存到 JSON *]  [复制布局到…]
工具：[选择/拖动/改尺寸] [画墙] [画传送区] [拉遮挡基线]
显示：☑背景 ☑前景层 ☑墙 ☑传送区 ☑物件 ☑出生点 ☑可走格  [重算可走格]  前景层[——●]
选中：物件 #0 桌子  x[92] y[152] 宽[76] 高[55]  遮挡基线Y[207] [恢复自动] [删除选中] [加出生点] [加物件] [导入图像…]
└ 下面这块是**选中项属性**（在限高的滚动区里，内容再长也不会把画布挤没、按钮也不会跑出屏幕）
物件属性（只在选中物件时出现）：id[__] 名字[__] 贴图[__][▾] ☐装饰 ☐遮挡 ☐恒在上层
互动内容：多句对话   说[我] 位[右] 表情[protagonist/reading] 词[……] [↑][↓][✕]   [加一句]
<下面一整块是画布>
```

**星星（`保存到 JSON *`）= 有没保存的改动。**

画布上每种颜色的意思：

| 颜色 | 是什么 |
| --- | --- |
| 红色方块 | 实体墙（`walls`，走不过去的地方） |
| 青色方块 | 传送区（`portals`，走上去按交互触发） |
| 绿色方块 | 物件（`actors`，家具、NPC） |
| 黄虚线 | 遮挡基线 —— **自动**（= 贴图框的下边界） |
| 橙虚线 | 遮挡基线 —— **手动**（写了 `cover_y`，见第五节） |
| 紫点 + 名字 | 出生点（**可选中、可拖、可改坐标**） |
| 绿色网格 | 可走格（`WalkGrid` 算的，和真机一致） |
| 橙色虚线框 | **前景层**的实际范围，标注「恒在角色之上」（它不是物件，见第九节） |
| 白框 + 八个白点 | 当前选中项；白点是改尺寸的手柄 |

---

- 复制布局、删除确认、加出生点这些**弹窗**，内容放在**限高的滚动区**里 —— 条目再多，
  底下的「确定 / 取消」也永远在屏幕内（之前内容一长就会把按钮顶出屏幕，点不到）。
- 「选中项属性」那一块也一样在滚动区里，行数再多也不会把画布挤没。
- 选地图那个下拉不会被长名字撑宽。

## 四、几件常做的事

### 1. 画 / 改碰撞箱

- **画新的**：点「画墙」→ 在图上按住左键拉一个框 → 松手就进 `walls`。
  刚画完会直接选中它。
- **改已有的**：切回「选择」→ 点中一个红块 → 拖着走；或用八个白点拉边角。
- **抠数字**：选中之后在上面的 `x / y / 宽 / 高` 里敲，画面立刻跟着动
  （「差 4 像素」这种话，现在直接敲 4）。
- **删掉**：选中之后点右边那个 **「删除选中」**（`Delete` 键同样管用）。
  删错了别慌：**没保存之前点「重新载入」就能全部撤回来**。

### 2. 画 / 改传送区

跟画墙一样，只是工具换成「画传送区」。新画的会自带：

```json
{ "rect": [...], "label": "新传送区", "locked": true, "blocked_text": "（还没有连接）" }
```

`locked: true` 的意思是**摆在这儿但还不通往任何地方**（走上去弹那句话）。
要真接上，去 `portals` 里补 `to` + `spawn`（或者 `event` 挂一段剧情），
再把 `locked` / `blocked_text` 去掉。

### 3. 把一张图的布置复制到另一张（白天版 ↔ 夜间版）

点顶部 **「复制布局到…」** → 选目标地图 →「覆盖过去」。

- 复制的是**碰撞箱、传送区、物件**这三样，在目标图里**整个换掉**。
- **尺寸、背景、前景层、音乐、脚步都不动** —— 那些是每张图自己的。
- 出生点默认不动；要一起复制就勾上「连出生点一起复制」。
- 覆盖是**立刻写盘**的（不用再点保存）。做完看一眼状态栏那句话。

> 用在「同布置、不同配色」的图上：白天版摆一遍，覆盖到夜间版。
> **反过来也成立** —— 夜间版摆好的，也能覆盖回白天版。

### 4. 拉遮挡基线（就是那个「挡不挡人」的分界线）

1. 点「拉遮挡基线」。
2. 点一件**身上有黄/橙线**的物件（只有写了 `cover: true` 的物件才有）。
3. **上下拖**，线跟着走；松手就写进那份 JSON 的 `cover_y`。
4. 拖完之后线变**橙色**（= 手动覆盖）。想回到自动，点「恢复自动（贴图底边）」。

什么时候需要手动拉：**贴图底下自带一圈阴影、或者切件时多切了几像素**，
「贴图框的下边界」就不是物件落在地上那条线了 —— 摊上这种情况才拉。

> ⚠️ 写了 `cover_y` 之后，那件物件的 `rect` 底边**就不再管遮挡**了。
> 只在该手调的那几件上写，别养成每件都写的习惯。

---

### 5. 出生点（玩家进这张图时落在哪儿）

- **改位置**：切「选择」→ 点那颗紫点 → 拖着走；或在 x/y 里敲数字。
  （出生点没有「宽高」，那两个框对它自动禁用。）
- **加一个**：点「加出生点」→ 起个名字 → 它先落在**地图正中** → 再拖到位置。
- **删一个**：选中 → 「删除选中」。**有跨文件关联的会先弹确认**，把挂着的东西列出来
  （见下面「删除与关联检查」）。

**命名规矩**：出生点是按名字被引用的 —— 传送点写 `"spawn": "<名字>"`，
新游戏固定找 `start`。所以：

- 名字**别重复**（重了编辑器不给加）；
- **至少留一个 `start`**，不然新游戏和一部分传送点会指空；
- 习惯命名：从哪儿来的叫 `from_<来源>`（`from_overworld`、`from_desk_shop`）。

> ⚠️ **出生点只管「落在哪儿」，不管「朝哪儿」。** 数据里 `spawns` 只有坐标，
> `enter_map()` 也只设位置 —— **没有任何一处按它设朝向**。玩家进图时的朝向是
> 「上一张地图带过来的朝向」，新开局则是默认朝向。
> 想固定朝向（比如进门朝上），得在**剧情**里用 `place_player`，或者在那段入场的
> 代码里写一行 `player.facing = Vector2.UP`（门卫室那张图的调试分支就是这么干的）。
> 如果以后要「每张图/每个出生点自带朝向」，得往数据里加字段（现在没有）。


### 6. 物件（家具与 NPC）：加一件、改名字、编互动内容

选中一件物件，面板下面会多出一块 **「物件属性」**。

**加一件**：点「加物件」→ 它先落在地图正中（40×40 的绿框）→ 拖到位置 → 再填下面的信息。
**「加物件」旁边那条「导入图像…」**：从电脑上挑一张 PNG → 它会被拷进 `art/props/`
（名字自动收拾成小写下划线，重名加 `_2`）→ **新建一件默认勾上「会挡人」的遮挡物件** →
你拖到位置、拉它的黄基线。**从美术给的图里挑一块做遮挡片，走这条路。**

**能改的：**

| 字段 | 说明 |
| --- | --- |
| `id` | 内部标识，一件图里别重名 |
| 名字 | 显示名；没贴图时就画这个名字 |
| 贴图 | 直接写 `res://art/props/xxx.png`，或用右边的下拉从 `art/props/` 里挑 |
| ☐ 只装饰 | 勾上 = 只画、**不参与交互**（玩家走过它不会弹出交谈） |
| ☐ 会挡人 | 勾上 = 按站位分前后（人在它北边被它盖住） |
| ☐ 永远画在角色之上 | 给前景小物件用（一直盖着人，不按站位） |

**互动内容**面板会显示这件物件当前用**哪种写法**：

| 写法 | 面板上怎么编 |
| --- | --- |
| 单句旁白（`line`） | 一个输入框，写完事 |
| 多句对话（`talk`） | **一行一句**：说话人 / 左或右 / 立绘（下拉，含主角表情）/ 正文，行尾有 `↑` `↓` `✕`，底下「加一句」 |
| 挂剧情事件（`event`） | **只读**：显示它在 `data/events/<id>.json` 里，编辑器不编剧情正文 |
| 多动作菜单（`actions`） | 只读（暂不编辑） |

右边两个按钮可以在「单句旁白 / 多句对话」之间**换写法**（原内容会搬过去）。
挂了剧情事件或动作菜单的物件，编辑器不去动它 —— 想改成对话，得先去那个文件里把 `event` 摘掉。

> **说话人留空 = 旁白**；主角说话就填 `我`，侧别选**右**，立绘挑 `protagonist/…`
> （哪张表情用在哪，看美工那份《表情使用方法.txt》）。
>
> **编辑器不会把不认得的字段抹掉** —— 比如对话行里的 `size_delta`（字号增减）、
> `shake`（抖动）它不显示，但保存时原样留着。你要写这类效果，还是得手改 JSON。

### 6.5 删除与关联检查（防手滑）

删东西之前，编辑器会查**跨文件的关联**，有就列出来让你确认：

| 删什么 | 会提醒什么 |
| --- | --- |
| 物件 | 挂着剧情事件「ch1_sleep」／动作「睡下」挂着事件／有出现条件（if）／演完会写状态（item/key） |
| 传送点 | 连着地图「overworld」／挂着剧情事件／动作是 overworld／现在是锁着的 |

**为什么要拦**：这类错误**数据完全合法，`check_data` 查不出来** —— 它只查「引用的东西存不存在」，
查不出「这里本来该有个人来触发」。删掉之后正文文件还在，只是**再也没有入口**了。

同样地，给一件挂着剧情的物件勾上「**只装饰**」时也会先问一句（勾上它就不参与交互，
剧情同样触发不到）—— 这条是伪装成显示选项的陷阱，所以单独拦。

### 7. 前景层（那道「挡人的下围墙」，可以直接点它）

前景层是 `overlay`：一整张图，**恒在角色之上**，**整张拉伸到地图大小**。

**选中它**：切「选择」→ 点那块橙色虚线框里的地方。
它常常压在墙上、门洞上，别的层会先被点中 —— 想干净地点它，就把「墙 / 物件」
那两个勾**先取消**（显示开关同时管能不能点中）。选中之后面板上会出现：

| 控件 | 作用 |
| --- | --- |
| 图片 | 直接的路径输入框，敲完立刻换 |
| **导入图像…** | 挑一张 PNG 拷进 `art/map/`，按习惯命名 `<地图名>_wall`，并设为前景层 |
| 清除 | 把前景层去掉（数据里那条没了，图还留在 `art/map/` 里） |

**图的尺寸不用管** —— 游戏里它会被拉伸到整张地图（`map_view._add_overlay`）。
所以美术给的图多大都行。

**它没有位置和尺寸可调**：数据里前景层只有一条路径。那四个数字框对它自动禁用，
拖也拖不动。要改「挡住哪儿」，改的是**图本身**（画的时候就在图里定好了）。

**看它盖住了什么**：显示行最右那个「前景层」滑条拉淡。

**下围墙两种做法的分工**：

| 做法 | 数据长什么样 | 哪些图 | 编辑器的表现 |
| --- | --- | --- | --- |
| 前景层 | `overlay` 一个路径 | 卧室、委托屋、门卫室 | 铺一张图 + 橙色虚线框，**能选中、能换图** |
| 遮挡物件 | 一个 `cover: true` 的 actor | 集市（`bottom_wall`）、门卫室的桌子 | 绿框 + **可拖的黄基线** |

> 什么时候用哪种：人**只会**在它前面走 → 前景层（恒盖，最省事）；
> 人**既会在前面也会在后面**（门洞过道那种，人在前面时不能被墙压住）→
> 遮挡物件，按基线切换。

## 五、可走格（验「人到底能不能站这儿 / 走得过去」）

勾上「可走格」→ 面板底下会铺一层网格：

- **绿色格** = 人站得住（脚底方块 16×16 放得下）
- **红色格** = 站不住

**改完墙之后点一下「重算可走格」**（算一次要一两秒，它把整张图逐格问了一遍
`WalkGrid.is_free`）。

这一层是拿来验这几件事的：

- 新画的墙有没有把路堵死；
- 两道家具之间那条缝，够不够 16 像素的脚钻过去（缺口问题就是这么找出来的）；
- 门口那块传送区，里面到底有没有一格站得住。

## 六、显示开关的两个作用（容易踩）

那一排勾选框**不只是显示/隐藏**，它同时决定「这一类能不能被点中」：

- 物件压在碰撞块上是常事（委托屋的书桌、门卫室的桌子）。物件开着的时候，
  你怎么点都是选中物件，底下那块墙**永远点不到** —— 这时把「物件」取消勾选，
  再点就选中墙了。
- 反过来也一样：只想调物件、不想误碰墙，就把「墙」关掉。
- 把某一类关掉时，**挂在它上面的选中会一起收起来**（不然会出现看不见的白框
  还挂着八个手柄）。

## 七、保存与回滚

- 改完点「保存到 JSON」→ 直接写回 `data/maps/<地图>.json`。
- **格式是对着 git 友好做的**：整数写成整数（`96` 不是 `96.0`），
  键序不动，两空格缩进 —— 只有你改过的那几个数字会出现在 diff 里。
- 改坏了：`git checkout -- data/maps/<地图>.json` 就回来了（编辑器不做备份，
  项目有 git）。
- 「重新载入（丢弃改动）」= 从磁盘重读，丢掉这次没保存的改动。

**保存完，游戏里不会自动变** —— 游戏每次进地图都从 JSON 读，
所以下次进那张图（或重新跑一次）就是新的。

## 八、这个版本里没有的（别找了）

| 想做的事 | 现在去哪儿做 |
| --- | --- |
| 出生点带朝向 | 数据里没有这个字段（朝向归剧情 `place_player` 管） |
| 改剧情、台词、交互 | `data/events/*.json`（编辑器不碰剧情） |
| 从插画上切贴图、定物件的贴图框 | 还是 `tools/slice_props.py` 那套（编辑器只引用 `art/props/` 里已有的图） |
| 编剧情正文（事件里的分支、演出、选项） | `data/events/*.json` —— 编辑器只在物件的「互动内容」里**引用**事件，不编它的内容 |
| 加/改地图本身（换背景图、改尺寸） | 手改 JSON + `tools/make_gatehouse_assets.py` 那类生成脚本 |
| 双画布 diff 提遮挡物 | 还没做（第三步的活） |
| 编辑前景层的形状（画/擦它的像素） | 还没做 —— 那是改画，得动 PNG |

## 九、出问题了先看这两处

1. **面板一片空白**：先在「地图」下拉里选一张图 —— 打开时载入的是列表第一张，
   可能不是你想要的。
2. **画面卡一下**：勾「可走格」或点「重算可走格」时要算整张图，
   大图会顿一两秒，正常。
