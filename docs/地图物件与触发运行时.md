# 地图物件与触发运行时

2026-10-23。以下字段由游戏主线读取；运行游戏不依赖地图编辑插件。

## 视觉部件

旧物件继续使用 `sprite` 与 `rect`。非空 `visual_parts` 数组会替代单张贴图，每项含：

| 字段 | 作用 |
| --- | --- |
| `id` | 可选、同物件内唯一的部件标识 |
| `sprite` | `res://` 贴图路径 |
| `rect` | `[x,y,w,h]`，相对物件矩形左上角，宽高须为正数 |
| `layer` | `back` 固定后层、`auto` 按站位遮挡、`front` 固定前层 |
| `sort_offset` | 自动层相对该物件有效遮挡基线的偏移，默认 0 |

各部件共用原物件的交互、条件和碰撞。拆分部件不会产生额外可交互物件。
`auto` 的基线为 `Actor.effective_cover_y()` 加部件偏移，继续遵守手动基线覆盖、参考碰撞框上缘与旧图回退规则。

`quarter_turns` 是 0 至 3 的顺时针 90 度次数，`flip_h`、`flip_v` 是布尔值。
贴图先局部翻转，再旋转；编辑器已把 `rect`、`collision`、`reach_local` 和各部件矩形烘焙到新几何中，运行时只变换贴图。
手写这些字段容易导致几何与贴图不一致，应使用插件的变换按钮。

## 地图触发区域

地图可选 `triggers` 数组，每项包含唯一 `id`、矩形 `rect`、已存在的剧情 `event`，以及：

| 字段 | 作用 |
| --- | --- |
| `mode` | `enter_map` 进入地图、`enter` 进入矩形、`interact` 区域内按交互键、`click` 点击矩形 |
| `enabled` | 是否启用，默认 true |
| `once` | 当前存档只成功启动一次，默认 false |
| `condition` | 可选的既有 Condition 条件字典 |

`enter_map` 进入后等待空闲入口；`enter` 在由外到内时排队。剧情忙碌或暂停期间不消耗触发状态。
条件不成立或事件无效不会标记成功。交互与点击仅在对应输入时查询，交互仍优先处理脚下传送口。
同一帧按数组顺序最多启动一个事件，复用既有剧情导演与玩家控制流程。

`once` 使用 WorldState 命名空间 `map_trigger/once/` 持久化，正常保存与读档恢复；新游戏随世界状态清空。
切换地图会清除运行器的临时进入边缘和待执行队列。

编辑器只绑定已经存在的事件。剧情节点、选项分支和演出指令的编辑另等用户明确要求。
