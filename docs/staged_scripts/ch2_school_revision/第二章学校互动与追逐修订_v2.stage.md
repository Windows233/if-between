## 制作顺序

1. 旗杆：保留原台词“旗杆上挂着的不是旗，是一个小孩的外套，袖口有猫毛”，确认调查可触发并恢复控制。
2. 秋千与救援：进入时协调底图 C、独立 C 和束缚层；救援改为三段连续解线，每段正确输入才推进，错误累计 2 次失败，可从 rescue 检查点重试。现有 rescue 没有难度参数，需要程序补进度、错误计数、暂停和重试清理。成功后继续现有 C 初见、白塔、蚀界和组队对白。
3. C 与教学楼：替换 ch2_c_wait 当前去 school_gate/near_yard 的路径，落到教学楼门口附近。对话结束 C 变为不移动、不跟随、不挡门的静态 NPC；玩家手动进入 classroom。
4. 教学楼调查：新增 classroom 的公告栏和镜子 actor。公告栏显示“贴满旧通知，日期都是同一天：6月 ？日”和“六年二班XX同学，请到图书馆。你的猫在等你”；镜子显示“镜子上的雾气里有一行字”和“猫是人类的好朋友，猫怎么会无缘无故伤害你呢”。确认后都收图并恢复探索，不触发追逐。
5. 日记：把当前单张 ch2_diary_written.png 拆为三页或补交三张图。P467、P468、P469 逐页显示、逐页确认、逐页收图；第三页关闭后才获得日记本、写 diary_read、显示 OS“原来是对抛弃一直不能释怀吗”，之后才播放猫叫。
6. 追逐：保留 Q1/Q2 的 Q/E 判定。失败或被追上不进入 End5，统一清理计时、慢动作、镜头、黑雾和输入监听，然后由 C 在校门门前救场，保留“小心！”、“你没受伤吧”、主角“.....没有，我们快去图书馆吧”。救场后入馆补 C：“看来有人在这里出事，我们得小心一点了”，主角接“怎么了？”，C 留在入口不动。
7. 双 QTE 成功：进入图书馆，不生成救场 C，只显示 OS“他怎么能到得这么快，而且，他怎么知道我在这里”，随后恢复探索。图书馆内后段的另一套追逐不在本稿范围。

## 状态与验收

三页日记完成后才设置 diary_read；救援成功才设置 rescued_c；被追上救场设置 caught_rescued，不设置 End5。成功、救场、重试、读档、切图都必须清理追逐临时状态。验证标准是：日记分页和奖励时序正确，旗杆可查，秋千只有一个 C 且难度高于旧版，C 在门口固定，公告栏和镜子可独立调查，追逐两种入馆分支对白准确，所有临时实体和计时器可清理。
