# 解救C与两段追逐玩法补充案

版本 V3.1｜2026年10月21日

本稿替换原执行案中“两段追逐仅用短演出”的安排。追逐加入可操作的跑动、绕障与观察时机，复用现有地图、角色移动和危险区域，不增加敌人自由寻路。九天周期仍为六天制作、三天润色。

## 一 解救C的画面与操作

参考图使用现有操场、秋千、C与主角素材进行合成，并补绘因果线和界面。画面为概念示意，尚未实装；图中人物伸手动作与光效是视觉方向，不视为项目已有动作素材。

画面上方是三根线缠住C，下面是水平判定轨道。菱形标记来回移动，固定亮区表示本轮可稳定的窗口。图中第一根已稳定，正在处理第二根。

- 操作：标记进入亮区时按空格或确认键，也可点击确认按钮。
- 一次成功解开一根线，共三根；失误不清空已经解开的线。
- 开始前有一次不计错练习。未按可以等下一个周期，不扣次数；按住只判定一次。
- 按早／按晚显示明确反馈，确认后再继续；累计三次失误进入End 4。结局后直接重试，不重走地图。
- 成功时黑线变淡、C恢复一点活动；失败时黑线收紧，不用强频闪。
- 先采用宽容判定，三轮初始窗口约35%、30%、25%；图中亮区比例仅示意，实际以试玩为准。

最终版本只保留游戏画面，参考图右侧四条说明用于团队沟通，不常驻游戏。场景已烘焙了C，接入独立角色时要清理底图人物，避免重复出现。

## 二 第一段追逐 从猫的扑击中跑到图书馆

### 目标与场地

选对图书馆后，主角从教室离开，目标是穿过校门广场抵达图书馆门前。沿用现有校门图：教学楼在左上、喷泉在中央、图书馆在右上。路线为教学楼门前 → 喷泉南侧可走通道 → 东侧灯下转角 → 图书馆门前。

先把起点、终点放在门前实际可走的地面上，修正现有触发框与墙体重叠的问题。不能把进门成功区放进实体墙。首次包含提示约四十至六十秒，熟练有效操作约二十至三十五秒，最终按实机路径调整。

### 操作与提示

WASD或方向键移动，沿用现有走路速度，不新增冲刺、跳跃和翻滚。开场镜头短暂指向图书馆亮门，显示“到图书馆门前与C会合”。追逐中保留明显终点标记，关闭普通调查和错误地图出口，避免误触对白或离开关卡。

| 段落 | 玩家实际要做什么 | 危险与反馈 |
| --- | --- | --- |
| A 教学楼到喷泉南侧 | 先跑出起点，再绕开前方落点，沿喷泉下方通过 | 开跑先给约三秒无攻击时间。玩家经过触发线后，前方出现带爪痕的地面预告；约一秒后猫影扑向该处。预告一出现就锁定落点，不能追着玩家刷新。两侧至少保留一条真正可走的绕行通道 |
| B 东侧灯下转角 | 站到暖灯安全点观察，再看准空档穿过通道 | 灯下安全，逼近暂停。前方为“约一秒预告 → 约半秒扑击 → 约两秒收招”的固定循环。玩家在收招时起跑，利用脚步和画面一起判断，不再弹横条小游戏 |
| C 图书馆门前 | 越过门前成功线，进入亮门区域 | 进入成功区立即锁定胜利，再播放C开门拉人的短演出。护身符闪一下，留下C来得太快的伏笔。不能先强制打中玩家，再让C救场 |

### 追赶压力与失败

不让猫沿地图自由寻路。猫在身后或画面边缘按固定路径表现，追赶压力由一条清楚可见的“黑影逼近”条承担；真实伤害只有预告危险区。

每段允许时间先按“正常走通时间约两倍，加一次完整等待扑击的时间”设置，再试玩调整。起点说明、灯下安全点、暂停和窗口失焦时不增长。处于普通道路时逼近条缓慢增长，让停在危险道路上有代价，不要求玩家极限冲刺。

被扑中不立即死亡：逼近条增加约三分之一，并有短暂受击保护，同一次扑击只扣一次。逼近条满才被抓住，进入End 5或对应重试界面，不增加新的猫追逐结局。

失败从最近的安全点重试：起点或东侧灯下。不会重读教室日记、重做选路。重试时危险从未激活阶段开始，给短暂准备时间；到达灯下后以新的分段额度开始，不把第一段的失误带进必败局面。

### 必须遵守的公平规则

- 扑击锁定后不追踪玩家；预告纹样与实际命中范围一致。
- 判定用脚下的小范围，角色头发、围巾碰到边缘不算命中。
- 安全点能看见下一处危险，首次规则说明出现时所有危险暂停。
- 终点成功优先于同一瞬间的伤害，不出现“进门了却判死亡”。
- 等待空档不超过几秒，不靠长时间罚站增加难度。

## 三 第二段追逐 借书架摆脱C

### 目标与顺序

这一段突出“用回溯得到的知识脱身”，不重复第一段全程奔跑。沿用图书馆现有书架与南侧门。流程为刀锋闪避 → 最近书架后安全点 → 查出护身符定位 → 丢弃护身符 → 观察C朝向 → 穿过一条书架通道 → 南门离开。

### 三个操作阶段

1. **先闪避，再进入安全点。**再次对峙时，用救援关同一套时机按键完成一次侧身。成功后隐蔽发动，主角退到最近书架后。闪避失败按End 7处理，直接从闪避前重试。
2. **安全地调查定位来源。**目标改为“找出C仍能追踪你的原因”。检查结晶，显示隐蔽仍有效；检查玩偶，猫叫或文字指向护身符；检查护身符，暗纹与C脚步同频亮起。此时不跑倒计时，C只在通道外停留。丢弃后发光停止，目标变为“趁C转身，前往门口”。不新增投掷、诱饵落点或物理系统。
3. **看空档，穿过通道。**一处书架背面为出发安全区，门前书架背面为第二安全区。中间只有一条危险通道。C在固定位置转头或短距离往返，循环为“约一秒转头预告 → 约两秒看守 → 约三秒看向另一侧”。玩家观察后用移动键通过，不需要潜行按键。

### 看守与暴露规则

地面细边框与淡色扇形显示C当前看守的通道，小人朝向和提示文字同步变化。只在预设通道内判断，不制作整张地图的复杂视线系统。书架背后的指定地面安全，不要求玩家猜哪个像素能藏身。

进入看守区域后，“暴露”条约一秒填满才被发现。及时退回书架后，条逐渐消退；首次轻微暴露给主角轮廓一闪和C回头，提醒玩家还有补救机会，不立刻全屏死亡。

暴露满时，C抓住主角，使用既定背刺失败结果，不额外新增结局CG。直接从已丢弃护身符的书架安全点重试，C朝向复位，暴露条清零。不要重做护身符推理、净化、回溯或刀锋闪避。

到达南门成功区后立即进入返程，剩余校园奔跑用短演出收尾，不再放第三段完整追逐。护身符处理后才开放这条逃生路线，之前从书架探头时给明确危险反馈，不放任玩家绕过核心推理。

### 第一段与第二段的区别

| 项目 | 猫追逐 | 逃离C |
| --- | --- | --- |
| 主要动作 | 连续跑动、绕开扑击、看空档起跑 | 在书架后停步观察、解除定位、穿越看守区 |
| 主要信息 | 地面落点预告、逼近压力、终点方向 | 护身符反馈、C朝向、暴露条 |
| 安全位置 | 起点与东侧灯下 | 书架后与门前书架后 |
| 成功条件 | 玩家自己跑进图书馆门前，C随后接应 | 已丢护身符，穿过通道到达南门 |
| 不制作 | 猫自由寻路、冲刺体力、跳跃翻滚 | 真正投掷诱饵、全图视线射线、复杂潜行动作 |

## 四 对九天任务的调整

新增可操作追逐会占程序时间，不能按“复用现有素材”记为零成本。两段共用预告危险区、进度条、暂停、重试与安全点；小游戏仅保留救C与刀锋闪避两种用途，追逐中不反复弹同一个按键条。

- D1：小游戏原型后，确认校门路线实际可走，标出两个危险区、灯下安全点和门前成功区。整合人员交位置图，程序不临时猜路线。
- D2至D3：整合者按模板整理调查内容，减少程序录入；主美术优先交角色、道具和必要分层，不把新追逐动画列必做。
- D4：先用临时安全跳转完成完整剧情首通，保留追逐入口和成功出口。当天的首通不冒充追逐已验收。
- D5：程序优先接通两段共用的最小追逐逻辑，文案与整合者按上述阶段逐段检查；暂停、受击保护和安全点重试一起验证。
- D6：只修复、整合与冻结。若D5结束仍未稳定，立即降为下述最小版，不把新机制开发挪进D7至D9。

最小版仍有实际操作：猫追逐保留“一次预告扑击＋跑到门前”，C追逐保留“书架安全点＋一条看守通道”。先取消额外转角、第二处扑击、C移动巡逻和复杂黑影动画。最小版若仍不能正确暂停、判定和重试，则回退短演出并明确登记该项未完成，不能以演出代替可玩验收。

## 五 本轮新增美术量

不重画校园与图书馆。复用现有猫透明图做黑影剪影；地面预告、目标门光、安全点、看守区和进度条用简单形状与局部光效。C复用已有朝向帧。救C黑线与断线反馈为补绘或程序表现，图中伸手动作可先用现有站姿替代。

最终验收：追逐路线能走通、预告先于伤害、预告不追人、读字不受罚、被击有补救、重试不重复长剧情、C救援发生在玩家达成目标之后。
