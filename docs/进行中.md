# 进行中

> **动手之前先读这里。** 几个人（和他们的 AI 会话）同时在改这个项目，

> **别留过期的行在这里**，比不写还坏。

| 谁 | 分支 | 正在改 | 开始时间 |
| --- | --- | --- | --- |


## 怎么填

- **谁** —— 名字或 GitHub 用户名，和 `git config user.name` 保持一致，别用花名。
- **分支** —— 你正在哪条分支上干活。不要在 `main` 上长线开发，见 `docs/协作约定.md`。
- **正在改** —— 目录或文件名。写宽一点更安全，`data/events/` 胜过 `ch2_meet_a.json`。
- **开始时间** —— 方便对方判断这行是不是过期了。

## 撞上了怎么办

两个人同时改同一个文件不是不可以，是**要先说一声**。

如果是不同区域（他改文件头，你改文件尾），git 大多能自动合。
如果都在改同一段，商量一下谁先做，另一个人等。

`core/` 里的公共类、`project.godot`、`export_presets.cfg`、`docs/开发纪要.md`
这四处没有商量余地，同一时间只能一个人动。
