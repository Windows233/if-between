# 美术交付约定：遮挡物（2.5D 遮盖用）

> **2026-10-22 适用范围修订**：下文保留旧版集市遮挡物提取流程。新对象式编辑器的碰撞箱由地图编辑师划定，自动遮挡判定取指定碰撞箱的上边缘，并允许手动偏移；贴图最下像素不再是新物件的默认排序依据。双画布仅供符合条件的旧素材提取，不要求全部地图照此重交，也不据像素差自动认定物件碰撞。新交付规范须经室内外试点审核，详见 `地图编辑器重制方案.md`。

> 这份写给美术。目标：图交过来，工具自动完成**拆件、定位、定基座、生成碰撞箱**，
> 不需要人工逐件对位置。
>
> 背景：集市那版「整张静态遮罩」要改成**逐件遮挡**——人站在摊位前方时不被挡、
> 走到摊位后方时被挡住。之后的学校地图（围墙、路灯、秋千、树木）走同一套。
>
> 工具认东西的方式只有两条：**位置靠双画布做像素差**，**基座靠切图的底边**。
> 下面每条规矩都是从这两条推出来的。

## 一、最省事的交付方式：双画布

每张地图交两张**同尺寸、同缩放**的 PNG：

| 画布 | 内容 |
| --- | --- |
| 完整版 | 现在这样，遮挡物都画在原位 |
| 镂空版 | 同一张画布，把「要挡人的物件」全部拿走，空出来的地方用合理的地面补上 |

工具把两版做像素差，差出来的每一块就是一件遮挡物——位置、轮廓、大小全自动，
不需要在展示图上量坐标，也不需要美术标基座。

白天/夜晚各一对，共四张。可以另附分件展示图（像集市 IMG_3992 那种），
**仅作参考，不参与提取**。

## 二、画布规矩（位置从哪来）

1. **双画布像素级对齐。** 除拿走的物件外，其余像素必须完全一致。
   任何一次「另存时缩放了」「重新导出了」都会让像素差失效。
2. **PNG 直出。** 不进 JPG，不反复保存。有损压缩会搅碎 1 像素的线。
3. **不烤辅助层。** 选区蚂蚁线、标注文字、示意色块不能留在图里。
4. **镂空处补合理地面。** 人要走到那些地方，脚下必须有地。
   不留白、不留灰、不留下没清干净的选区边缘。
5. **影子留在背景里，不跟物件走。** 落地范围按切图底部扫描，影子跟件走会让落点变宽。
   镂空版里物件原位置的影子可以保留。

## 三、单件规矩（基座从哪来）

工具认的「基座线」= **切图最下一排非透明像素所在的横线**。所以：

6. **底边就是接触地面的那条线**，切图底下不要留空行。
7. **底部保持干净。** 最下几行里不要有飘离主体的杂点（草根、碎石、悬浮的光点）——
   那些会被算成额外的落地碰撞块。
8. **一件遮挡物一条基线。** 棚、架、旗同属一个摊位，就画成连通的一块交付。
   基线不同的两件东西**不要互相接触**——粘住了就只能共享一条基线。
9. 悬空的东西（挂招牌、吊灯）自己没有基线：要么并进所属物件，
   要么在分组表里写明它挂在哪一件上。
10. 抗锯齿留 1~2 像素没问题，**不要大范围羽化半透明**——
	半透明边在前后切换时会透出背景。

## 四、碰撞箱怎么来（美术不用画，但受上面约束）

- **箱形物件**（摊位、柜台、墙段）：落地范围 = 底边那一带的整宽，工具自动生成。
- **窄底物件**（树、路灯、秋千的柱子）：工具按「底边往上几行里有哪些列有像素」
  取实际落地段，树冠不会堵路。
- 个别不对的，工程侧走手调表修。美术反馈时指认「哪一件」即可。

## 五、分组表（一张文本清单，工具猜不了语义）

连通块自动分组之后，需要人工确认一张表。每件标一个属性：

| 块 | 归属 | 排序方式 |
| --- | --- | --- |
| 示例：3 号块（紫棚+书架+旗） | 书摊，一个物件 | `cover`：贴地，按基线排序 |
| 示例：7 号块（路灯） | 单独一件 | `cover`：竖直高杆整件即可 |
| 示例：8 号块（横幅，横跨街道） | 单独一件 | `over`：悬在头顶，恒在上层 |
| 示例：9 号块（树） | 拆两件 | 树干 `cover` + 树冠 `over` |

**怎么标，判据只有一条：这东西会不会悬在「人站在它前面」的头旧行带里。**

- 贴地的、竖直的（摊位、路灯、旗杆）一律 `cover`。竖直高杆的灯头在图像最顶上
  的行带，人站在杆前面时头够不到那一带，不会被错误盖住；
  人站在杆后面被灯头压住，恰好是斜视角下 3D 正确的结果。
- **横向悬挑、人会从底下走过的**（横跨街道的横幅、雨棚外沿、树冠）标 `over`，
  恒在上层，不参与基线排序。这些不标的话会穿帮：人从底下走过，
  3D 上它明明挡在视线和人之间，基线排序却判「人在前」不挡。
- 拿不准的（比如摊位雨棚）：默认整件 `cover` 随摊位走，实测有异议再拆棚沿为 `over`。

树冠互相搭、两件在画面上不得不交叠时，在这张表里写清怎么拆。

## 六、命名与成对

- 文件名英文小写加下划线（工程约定既有规则）：
  `market_stall_book_day.png` / `market_stall_book_night.png`。
- 白天/夜晚：**同一套镂空范围**、同尺寸，物件切图两版共用同一组位置。
- 画布尺寸别再翻倍。6688×3764 一张 RGBA 约占 100MB 显存，
  学校地图若要更大，提前说，工程侧做分块。

## 七、自查清单（交之前过一遍）

- [ ] 双画布尺寸一致，除物件外逐像素相同
- [ ] 镂空处地面补全，无留白、无选区痕
- [ ] 图里没有蚂蚁线、标注文字、示意色块
- [ ] 每件底边干净，无飘离杂点；影子不在件上
- [ ] 基线不同的物件互不接触；交叠处在分组表注明
- [ ] 白天/夜晚镂空范围相同，文件成对，命名合规
