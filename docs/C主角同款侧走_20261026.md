## 当前生效版本

用户反馈八相位侧走僵硬。本版直接以主角side1—4作姿势参考，用内置imagegen重画C：收脚→迈步A→收脚→迈步B。第2帧屈肘向前摆，第4帧摆臂换侧，衣摆随迈步打开；围巾缩短以避免超出画布。身份仍为白发、灰围巾、深色长外套与长裤。

与主角同为四帧、8FPS、每轮0.5秒；第1/3帧复用同一收脚姿势。向左使用原图，向右镜像。停下回到同一收脚图，避免切换时跳姿。主角动画本身未改。
