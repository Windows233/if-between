# C 左右行走纠错

2026-10-26。承接 `d959114`，分支 `codex/c-side-gait-fix-20261026`。本轮仅本地提交，未推送。

## 原问题

上一版四张侧走帧都近似同一条腿在前，没有两脚互换的完整过程。此前“帧数正确、四张图不同、左右朝向正确”的检查不足以验收步态，旧四方向预览中的侧走部分已作废。

## 已更正

用内置 imagegen 重画侧走，再定向修正第3/4/6相位的腿部遮挡与深浅关系。八个阶段依次为：

1. 近侧脚在前落地，远侧脚在后蹬地。
2. 近侧脚承重，远侧脚抬离地面。
3. 近侧脚支撑在身体下方，远侧脚提起经过。
4. 远侧脚向前伸，准备落地。
5. 远侧脚在前落地，近侧脚已退到后方。
6. 远侧脚承重，近侧脚抬离地面。
7. 远侧脚支撑在身体下方，近侧脚提起经过。
8. 近侧脚向前伸，接回第一帧。

近侧靴保持较亮、远侧靴较暗，可以追踪同一条腿。手臂配合反向摆动。全组共用缩放与地面基线，身体锚点固定；不靠整个人平移、翻斜或逐帧变高来假装走路。
