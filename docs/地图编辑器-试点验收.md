# 地图编辑器室内外试点验收

> 状态：2026-10-22，准备阶段。本文记录候选场景、实测清单与人工确认项；未执行正式地图迁移，也未取得地图编辑师验收。

## 候选与当前数据

只读审计覆盖现有 14 张地图，均未配置物件局部 `collision` 与 `reach_local`。推荐先用门卫室做小范围室内验证，再用集市昼夜做室外对照；候选推荐不等于试点已通过。

| 候选 | 当前数据 | 覆盖目的 |
| --- | --- | --- |
| `gatehouse` 门卫室 | 2 件物件、19 段地图墙、1 个旧 `reach`、1 件独立贴图、1 件 `cover` / `cover_y`、整图 `overlay` | 桌子对话与破窗调查、物件局部属性、旧手动基线与前景层共存 |
| `market` / `market_night` 集市昼夜 | 每图 7 件物件、52 段地图墙；5 件 `cover` / `cover_y`，7 件均 `decor:true`；无 `reach`、`solid`、`overlay`，无局部碰撞 | 多类遮挡物、复杂通道、昼夜共享布局；交互验收由室内试点承担 |

门卫室的 `desk.rect=[92,153,76,40]`，旧基线 `cover_y=165`，`walls[5]=[92,165,76,40]`。它们适合作为人工核对对象，几何对齐本身不能证明这段墙属于书桌，更不能据此删除。破窗的旧交互范围相对贴图框偏移为 `[12,-29]`，改为局部交互后须保持可达性；破窗没有独立贴图，测试自由移动前需确认素材与背景补地。

集市昼夜的物件、墙与出口布局相同，两个地图中的 7 件物件均引用 `market_day_*` 素材；这项复用是否符合夜景效果需美术确认。三个摊位旧基线均为 107，喷泉为 188，划定碰撞后应逐项自然试走。当前有 12 段墙同时与至少两件物件的贴图矩形相交；例如 `walls[12]=[165,73,160,10]` 同时碰到白棚与红棚范围，不能自动分配。还需检查棚沿穿行、喷泉绕行、出生点及 4 个出口，保留各物件的纯装饰语义。

## 试点流程

只读盘点命令（在项目根目录运行）：

```powershell
python -B tools/audit_map_migration.py --output "$env:TEMP/if-map-migration-audit.json"
python -B -m unittest discover -s tests -p test_map_migration_audit.py -v
```

不传 `--output` 时把 JSON 输出到标准输出；可用 `--maps-dir` 指定另一份地图副本。退出码 0 表示本工具检查范围内没有问题，1 表示报告中有数据问题，2 表示参数或输出失败。报告不自动确定墙体归属，也不能代替完整数据检查与试走。报告输出被禁止写入地图目录或覆盖其硬链接文件。

2026-10-22 的实际盘点为 **14 张地图、80 件物件、278 段墙、29 个传送口、19 个出生点**，含 39 个旧 `reach`、19 个非空 `sprite`；局部碰撞、局部交互和编辑器分组均为 0。本工具范围内的问题数为 0，这些数字只描述现存数据。

先运行只读地图盘点工具，取得当前数据基线。在编辑器中载入候选图，用未保存布局试走；需要长期保存实验时另建试点地图，并先检查剧情引用与出口。原正式地图在审核通过前不批量转换。碰撞箱归属与大小由地图编辑师判断，工具不按距离把旧墙猜给家具。

测试对象应包含一件有独立贴图的可交互家具、一组可复制摆放的重复对象、至少一条窄通道，以及需要玩家前后走动的遮挡物。旧底图里已经烘焙的家具不能直接拖到别处；要验证自由摆放，必须使用独立物件和可用底图。

## 必须留存的证据

| 检查项 | 验收方式 | 记录内容 |
| --- | --- | --- |
| 旧数据基线 | 只读盘点与原布局试走 | 地图 ID、提交号、碰撞与交互来源、需要人工归属的旧墙 |
| 独立物件 | 放置一件家具，调整局部碰撞与交互区 | 贴图范围、碰撞框、交互框与指定排序碰撞框 |
| 自动遮挡 | 主角自然走到物件前、后与两侧 | 碰撞箱上边缘切换是否合理；手动偏移及恢复自动的结果 |
| 实例复用 | 复制整组，移动、对齐、撤销与重做 | 新 ID、原组与副本的属性独立，局部碰撞和交互随动 |
| 编辑组织 | 从场景树选择组与子物件，隐藏、锁定、定位、改组名 | 选区同步、锁定拦截、隐藏恢复，以及撤销边界 |
| 导航与物理 | 开可走格，试走窄道并靠近家具交互 | 可走判定与运行时一致；无重复墙导致的额外阻挡 |
| 持久性 | 保存、重开、载入备份并核对布局 | JSON 差异、备份可恢复、引用没有断开 |
| 素材需求 | 对照实际贴图与底图记录不能制作的对象 | 具体需要拆出的对象或补地面区域，不要求无关静态细节全部拆件 |

自动测试只能证明对应模型与操作链通过，不能代替自然试走、美术空间关系或地图编辑师确认。每项应记录地图、对象、操作、实际结果和证据路径；未测项标记待测，不填写通过。

## 当前结论边界

完整多级嵌套层级、拖放重排、模板继承和自动更新、复杂多段遮挡、区域触发器与剧情演出编辑均需独立设计和验证。完成场景树或盘点工具，不代表这些能力已经完成。现阶段物件模板仍是属性快照，运行时读取地图中的实例数据。
