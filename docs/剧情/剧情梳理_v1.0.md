# 整体剧情梳理 · v1.0

2026年10月23日整理。正本：[剧情修改1.0版.docx](剧情修改1.0版.docx)。

本稿依据本次指定的文稿，保留原剧情和关键措辞，不重写对白。工程对照核查于 `d7c2c31`。**这次只归档和梳理，没有把全文转成游戏事件，也没有新增玩法。** 下文“正文已有”与“游戏已实现”分别标注。

## 1. 故事主线

经营事务所的主角接下老人寻找黑猫的委托。委托看似普通，却让她经历死亡与重来，并接触到能观察、干预 IF 条件的能力。她为了找猫，与神秘人 B 交易，进入由执念侵蚀现实而形成的“蚀界”。

废弃学校里，主角救下自称白塔专案员的 C。C 提供解释、邀请组队，又赠送御守，让主角暂时把他当成同伴。调查学生证、黑板和日记后，主角逐渐拼出猫与被抛弃的经历有关；她进入图书馆，以日记作为媒介接近猫，取得“夜幕之泪”和猫玩偶。

C 随即索要结晶，被拒绝后刺伤主角。主角的回溯能力触发，回到第一次进入图书馆前。第二遍里，她保留记忆，发现血迹、书页和照片背后的新含义，也从猫口中得知自己的天赋与结晶品质的关系。

这次她提前防备 C 的攻击，借结晶的隐蔽能力和撬棍逃脱，却始终被追踪。最终她发现御守才是定位来源，将它抛出窗外，误导 C 后离开学校。B 收下结晶，老人收下猫玩偶，委托看似完成；黑屏上却显示条件被改写，C 又隔空发话，说明这场相遇只是更大事件的开端。

## 2. 第一章：猫

### 2.1 委托与第一次选择

开场黑屏出现三句关于委托、归来与黑夜的独白。主角在委托屋桌后醒来，老人从门口进来，请她找猫，却说不清丢失时间，只反复强调自己一定有一只猫。模糊照片建立疑点。

- **拒绝委托：**老人离开，日常继续，梦却反复出现。猫叫与画面破碎打断平静，进入 End 1“平静即死亡”。
- **接受委托：**老人补充“左耳缺一角、尾巴尖是白的”。主角打算翌日再找，回卧室休息。

### 2.2 梦境回环与观察教学

入睡后猫叫、碎屏和死亡画面出现，“这样就结束了吗，不甘心吧……”将主角带回委托屋。老人重新上门。玩家先选择“观察”，看到老人脑中的 IF 条件，此时只能看、不能修改。

回环后的委托仍有接受与拒绝两条出口。拒绝仍可进入 End 1；接受则进入下一天集市，不能把这一段误接成无限重复睡觉。

### 2.3 A 的死亡与第一次干预

集市里 A 正在修留声机。主角邀请 A 帮忙找猫，A 去公园，约好傍晚碰头。随后数日不见 A，路人提起动物撕咬痕迹；主角由此怀疑自己的邀请造成了后果，最终由猫给出答案，出现 End 2“甜蜜的咬痕”。

**这次 End 2 的呈现还承担教学作用：**之后进入 IF–THEN 教学，再回到邀请 A 的场景。条件发生变化后，A 遇见巨大黑影便逃离公园，得以活着回来，告诉主角黑影像猫。玩家由此体验“相同情境、不同条件、不同结果”。

### 2.4 B 的交易与进入蚀界

B 准确说出猫的特征，解释猫被“卷进门内”，拖延会令猫、委托和相关记忆逐渐消失。B 愿意开门，交换条件是主角带回一颗泪滴状黑曜石——夜幕之泪。

- **不相信：**继续寻找，委托登记变成白纸，委托人的住处也空了，进入 End 3“碌碌而无为”。
- **去就去：**取得未知吊坠和撬棍。吊坠“既是钥匙，也是路”，撬棍用于防身。B 留下“你还是你，他是他吗？”的提醒，消失；背景闪切至黑屏，进入第二章。

## 3. 第二章：蚀界

### 3.1 死巷与校门：建立规则和调查目标

蚀界停留在异常黄昏，影子紊乱、事物重复、猫叫伴随剥落。主角意识到这里是“猫快碎掉的地方”。死巷铁门令吊坠发热，B 出现在身后，说明现实中的封锁并不适用于这里。

进入学校后有四组调查：

| 调查点 | 获得的信息或物品 | 后续作用 |
| --- | --- | --- |
| 校门通知栏 | 晚上开放自习室；学校不处罚在自习室学习者；天黑后不得在校内游荡 | 宵禁选路的规则提示 |
| 易拉罐 | 钥匙 | 打开六年二班教室 |
| 门卫室登记册 | 别的名字被涂黑，主角已列在来访记录中 | 主角尚未明白的提前登记伏笔 |
| 中心雕塑 | “静候归期”与“但归期不至？” | 呼应猫等待主人归来 |

正文明确：**未推进到拾取日记本，不得进入图书馆**，门口提示“还没有到自习室开放的时间”。“晚上开放”与宵禁豁免构成后续选图书馆的依据。

### 3.2 操场：救援与建立对 C 的信任

旗杆挂着小孩外套，袖口有猫毛。沙坑中取得被撕去个人信息、只剩六年二班线索的半张学生证。

第一次查看秋千时自动存档，C 被线束缚，提醒“别碰线。碰了会——”。救援小游戏失败达到三次进入 End 4“自以为是的到来”；成功则解救 C。

C 对主角能直接引导因果线感到惊讶。经过自我介绍，他自称白塔分部专案员，并解释：强烈执念会让脑中的 IF 泄漏、侵蚀现实；白塔处理这些问题；破解蚀界能获得含能量的结晶。主角把这与 B 要求的夜幕之泪联系起来。

得知主角是主动进来找猫，C 告诉她：猫已与蚀界结合，拖得越久越不像猫。C 邀请组队并赠送道具，承诺“英雄救美”。**这份赠礼之后会被揭示为追踪来源。**

随后玩家可以选择准备出发，或继续调查；再次看秋千只出现黑毛与铁链摇动的后续文本，不应重演救援或重复发御守。

### 3.3 教学楼与六年二班：把调查转成答案

C 与主角约定分头找线索、在楼梯处集合。教学楼公告栏的通知日期相同，写着六年二班某位同学的猫在图书馆等她。镜子文字强调“猫不会无缘无故伤害你”。教室需钥匙打开，没拿钥匙可以回头寻找。

教室里的黑板写满“如果她回来，猫就会叫”，画着女孩、猫与门。课桌上的三页日记讲述：捡到猫、即将转学却带不走猫、猫一直哭。主角取得日记本，推断猫无法释怀被抛弃。

关掉日记后猫叫逼近，进入逃生选择。正文在这里还留有 C 出场与不在场的矛盾，见第 9 节。

### 3.4 宵禁选路与第一段追逐

选项为校门、操场、图书馆，**图书馆是正确答案**。

- 第一次选错，提示回想天黑后哪里还开放。
- 第二次选错，猫追至所选地点，进入 End 5“不可违的铁律”。
- 选图书馆后接第一段追逐，正文允许失误过多进入 End 5，同时要求最终有一处无法正常通关的异常，由 C 出手救援。

C 突然赶到，主角怀疑他为何知道自己的位置、又为何来得如此快。这与御守伏笔呼应。追逐的“普通失败”与“剧情必经的异常”应区别呈现，不能让玩家把剧情救援误认成自己的操作失败。

### 3.5 图书馆第一遍：得到成果，也遭到背叛

自由调查包括血迹、重复猫等待主人的童话书，以及中央地毯上的猫。C 尝试接近，却不能正常触碰猫；他嘀咕“不愧是夜幕之泪”，让主角出面。

玩家从已持有物品中选择介入媒介：错选会提示换一个，**只有日记本正确**。日记本消耗后，主角伸手，猫认出与主人有关的味道；随后取得夜幕之泪与猫玩偶。

C 索要结晶。主角因已答应 B 而拒绝，C 表面退让，随即刺伤主角。那句“可是，可”是作者刻意设计，须原样保留。C 感谢她带来高纯度结晶，并将她的能力视作利用目标。

主角的不甘触发回溯，显示“冷却时间 24h”。**回溯落点是第一次进入图书馆前；背包恢复该时刻的状态，人物保留这次经历的记忆。**文稿没有要求玩家在现实中等待 24 小时。

### 3.6 图书馆第二遍：信息反转

主角重新面对貌似亲切的 C，开始怀疑他的白塔身份，但正文尚未揭露他的真实组织。

三个调查发生变化：血迹被认作自己的；童话书多出“你等的人终会背叛你”；上锁盒子里有 C 与不明人物的合照，说明他的到来可能早有安排。

猫认出再次回来的主角，解释自己是蚀界核心，知道时间锚内的事情。带走结晶后，缺少维系能量的蚀界会消散。主角的血液带有时间种子，回溯让她同时关联现在与过去；她的天赋决定了能取得的结晶品质上限。

主角由此明白：C 想要的不只是眼前的结晶，她本人也可能是可被利用的高价值能力者。她考虑过投靠，却否定向随便杀人的组织求助，再次取得结晶与玩偶，准备离开。

### 3.7 闪避与第二段追逐：同伴成为猎手

C 再次索要结晶，主角拒绝。此时的闪避是主角已有防备、C 轻敌造成的**物理躲避**，不是夜幕之泪的能力。

- 闪避失败：进入 End 6“罪过”。
- 闪避成功：主角以撬棍抵抗、掀倒书架，阻挡 C 后逃向教学楼。

追逐中，主角尝试驱动夜幕之泪，获得“隐蔽”效果：能够屏蔽视线、气味，但不能摆脱追踪道具。因此隐蔽有效，却无法解释 C 为何仍能快速接近。

主角躲进教室后回忆赠礼，发现御守是定位来源，将它从窗外抛下。C 以为她选择跳窗，离开寻找。主角趁机逃走。抛出的是御守，**正文并没有让主角真的跳窗**。

### 3.8 交付与尾声：委托完成，事情没有结束

主角离开学校，集市的 B 在传送点旁等候。B 听到 C 的名字显出异常反应，收下夜幕之泪，允许主角保留吊坠。

主角回到委托屋，把猫玩偶交给老人。老人说这正是自己的猫：先前有猫把孙女的玩偶叼走。他支付十枚银币，离开。开场“找猫”在这里获得意料之外的交付含义。

黑屏出现三行：

> 条件已改写：猫 = 玩偶
> 学校：已关闭
> 夜幕之泪：已吸收

随后 C 再次对主角发话，期待正式见面，进入 End 7“未到的明天”。文稿未明确“谁吸收了结晶”、C 的真实组织与最终目的，不能擅自补成确定答案。

## 4. 分支与七个结局

| 编号 | 标题 | 正文触发点 | 叙事作用 |
| --- | --- | --- | --- |
| End 1 | 平静即死亡 | 初次委托或梦境回环后的委托选择拒绝 | 不介入也不能逃开异常 |
| End 2 | 甜蜜的咬痕 | 邀 A 找猫，未干预条件时的遇害路线 | 死亡后引出 IF 教学及重来 |
| End 3 | 碌碌而无为 | 拒绝 B 的交易，持续拖延 | 猫、委托与记忆消散 |
| End 4 | 自以为是的到来 | 秋千救援累计三次失误 | 显示介入因果线的危险 |
| End 5 | 不可违的铁律 | 宵禁选路连错；第一段追逐失误过多也可触发 | 规则违反的代价 |
| End 6 | 罪过 | 图书馆第二遍闪避失败 | 有记忆与警惕仍可能失败 |
| End 7 | 未到的明天 | 成功逃出、交结晶、交玩偶后的尾声 | 当前完整主线结局及后续钩子 |

正文中 End 6 的副句含“说拜拜吧”，不能用旧梳理中的截短句自动替换原文。End 7 是本版完整主线的收束，文稿没有把它明确命名为“真结局”或规定其他结局的收集前置。

第一章主干：接受委托 → 梦境回环 → 观察老人 → 接受委托 → A 的死亡路线 → IF 教学 → A 存活 → 接受 B 交易。

第二章主干：学校调查 → 救 C → 组队赠礼 → 钥匙开教室 → 日记 → 宵禁选图书馆 → C 救援 → 第一次取得结晶并遭背刺 → 回溯 → 第二遍调查与猫对话 → 闪避成功 → 隐蔽追逐 → 抛御守 → 交付 → End 7。

## 5. 人物关系与信息边界

| 老人 | 委托找猫；猫的特征与玩偶呼应；最终收下孙女的猫玩偶 | 记忆异常与条件改写之间的具体机制 |
| A | 修留声机的熟人；被邀后可能遇害；条件改变后逃离黑影 | 后续章节关系 |
| B | 知道猫的特征；能开门；索要夜幕之泪；赠吊坠、撬棍；听见 C 的名字有异常反应 | 与 C 的具体关系、是否预先知道全部风险 |
| C | 自称白塔专案员；利用主角取得高品质结晶；赠礼可定位；会背刺与追逐 | 白塔身份真假、所属组织、幕后目的 |
| 猫 | 与学校执念相连；是蚀界核心；记得时间锚内发生的事；能解释结晶与主角能力 | 女孩与老人家庭的完整关系，现实中的猫与核心的具体对应 |

“C 自称官方”和“C 实际属于官方”是两回事；“B 认识 C”也不足以推出两人合作。梳理保留这些悬念。

| 道具 | 获得时点 | 使用或失去 | 作用 |
| --- | --- | --- | --- |
| 猫的照片 | 委托屋 | 未要求消耗 | 委托凭据、模糊信息与猫特征 |
| 未知吊坠 | B 交易 | 结尾 B 明确保留给主角 | 开门与通路 |

| 半张学生证 | 沙坑 | 媒介可错选；未要求因此消耗 | 六年二班线索 |
| 日记本 | 教室课桌 | 第一遍介入猫时消耗；回溯后按进馆前背包恢复 | 唯一正确介入媒介 |
| C 的赠礼／御守 | 救 C 并组队 | 教室窗边抛出 | 前期信任、后期定位伏笔 |
| 夜幕之泪 | 图书馆，两遍各取得一次 | 回溯撤销第一遍结果；最终交 B | 高品质结晶、隐蔽能力 |
| 猫玩偶 | 图书馆，两遍各取得一次 | 回溯撤销第一遍结果；最终交老人 | 找猫委托的实际交付物 |
| 合照 | 第二遍上锁盒子 | 未要求消耗 | C 预先介入学校的证据 |
| 银币 ×10 | 老人结算 | 正文无消费场景 | 委托报酬 |

**回溯不能简单写成“只把日记加回来”。** 应恢复首次进馆前的完整背包快照，撤销进馆后新获得或消耗的物品，同时让主角记得背刺。二遍调查进度和记忆状态也需与普通物品状态分开管理。

## 9. 正文仍需确认或整理的地方

以下是阅读和实现问题记录，不自动改写正本，也不撤销此前用户已明确作出的决定。工作区既有决策记录可供后续核对，但建议与待定项不能混为已定稿。

1. **主角名字。** `yn` 明确是 your name 占位，不能直接作为正式姓名。既有记录提到开局输入、只替换正文；真正实现时需核对姓名输入、存档、旧存档回退及说话人“我”的处理，本次不新增姓名系统。
2. **未知日期。** 蚀界的“？月？日”“未知”是刻意设定，保留；不把它们列成缺文案或擅自补日期。
3. **C 的刻意断句。** “可是，可”原样保留。其他如“你受伤吧”“怎么他回来”等句是否缺字，另列校对，不能与这句一并自动修正。
4. **猫逼近时 C 是否在场。** 正文同一段既写“C出现在教室门口”，又让主角说“不知道C又去哪里了”。旧梳理把它总结成“C不在”，这个结论过于确定，需作者给出最终出场时序。
5. **第一段追逐的失败语义。** 既有可因失误进入 End 5 的描述，又有最终无法通关、由 C 救援的要求。实现时需把普通失败和剧情异常分别定义，不对玩家隐藏必败判定。
6. **第二段追逐被追上。** 正文没有明确给出出口；既有决策记录写复用 End 5。后续实现以用户确认的记录为依据，不沿用旧梳理中“建议 End 6”的过时意见。
7. **上锁盒子的规则。** 文稿允许小解谜，但没有题目、提示、答案或失败处理。既有记录中“三个锁扣按顺序点”仍属于候选形式，不因入库变成最终规则。
8. **二遍媒介是否再次消耗。** 回溯恢复日记本；第二遍正文直接进入猫对话，未重复写选择媒介和失去日记。后续需要明确是自动识别、复用操作，还是保留日记，不自行多扣一次。
9. **赠礼命名。** 正文“道具xx”“道具x1”和说明中的护身符，工程目前统一为御守 `charm`。后续可沿用这个映射，但不在原DOCX中直接替换作者文字。
10. **扔御守后的回程。** 正文明确抛御守、C离开，之后尚有走位或跳转两种表现备选；不存在已定的第三段追逐。现有地图也不能据“拿到结晶”就放行，需等剧情确认逃脱，避免绕过 C 段落。
11. **美术文字与新规则。** 入库的校门公告栏图仍写“24h开放”，与新版自习室规则不一致。后续做游戏文本时要同步图中文字。登记册图未显示主角姓名与正文“主角已登记”的信息也需统筹，不单独武断要求美术补固定名字。
12. **尾声信息边界。** “夜幕之泪：已吸收”的主体未说明；C 的真实组织、猫与女孩的完整身份关系未明。梳理保留为悬念。

## 10. 后续接入可按什么顺序推进

这只是依赖顺序，不是本次已经实施的任务：

1. 对齐第一章回环、姓名与基础道具；更新校门规则、学生证措辞、C 完整介绍。
2. 接通组队出发、教学楼与教室调查，锁定日记取得后才开放图书馆的条件。
3. 明确宵禁和第一段追逐规则，接图书馆第一遍、介入媒介与背刺。
4. 实现并验证进馆前快照恢复，接第二遍新信息、盒子和猫对话。
5. 接闪避、追逐、隐蔽、御守定位与回程，最后接 B 和老人交付、End 7。
6. 核对所有失败/重试、道具重复领取、旧存档、暂停和读档恢复，再补齐缺少的CG、动画与音效。

这份正文的核心体验是三次认知变化：**找猫的委托 → 蚀界与条件干预 → 被利用的能力者**。第二遍图书馆不能只重复第一遍台词，应让玩家用已有记忆识破同一场景里的新含义。
