# 可选 Godot 地图插件维护

此文件与 `addons/if_map_editor/` 只属于 `feat/map-editor`。游戏、地图、素材及公共运行时修改均归 `main`；插件分支合入主线更新，不能将整个插件分支合回主线。

## 2026-10-22 界面与素材比例修复

- 素材原始像素按背景源图宽高与地图尺寸换算，两个方向分别计算；新增、赋图、恢复尺寸采用同一规则。无可读背景时才保持原像素到地图单位的直接比例。
- 拖动素材预览使用换算尺寸乘以画布缩放，鼠标对准中心；最终落地保留浮点宽高，移动、对齐、复制不再悄悄取整尺寸。
- 下拉改在鼠标松开后打开，避免弹窗向上覆盖按钮时被同一次释放立即选中并关闭；长素材名不再撑宽属性卡。抽屉与下拉通过实际 viewport 鼠标事件检查。
- 拉基线、画物件碰撞移入物件属性卡；多选保留主选属性入口，物件专属画布工具只在单选可编辑对象时使用。
- 保留局部碰撞 x/y/宽/高、交互矩形、排序参考碰撞、排序偏移、手动基线及恢复自动。维度输入使用匹配的最小值与步长，避免量化成额外的 0.001 偏移。

旧提交 `c68a226` 所称的物件“原像素 1:1”把源图像素直接当成地图单位，这一解释已作废。正确关系是物件源图像素与背景源图像素一致，屏幕显示大小另受画布缩放影响。

## 验证

`tests/run_tests.gd` 只验证游戏；`tests/run_map_editor_tests.gd` 单独运行插件数据、几何、素材放置和 GUI 测试。`tests/test_map_inspector_ui.gd` 也可单独运行，使用隔离 SubViewport 合成鼠标输入，不操作桌面鼠标或键盘。`tests/probe_map_editor.gd` 核对完整面板、层级、撤销、备份和窄窗口；`tests/test_map_preview.gd` 支持独立运行布局试走。

本轮插件回归 **2960/2960**，其中属性卡真实 GUI 检查 **58/58**；完整面板探针通过，均为真实退出码 0。检查使用隔离 `APPDATA`，后台截图确认正式 `library` 的属性卡能完整显示局部几何参数。游戏实际窗口仍需策划确认手感；自动测试不等于人工验收。
