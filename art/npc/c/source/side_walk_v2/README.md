# C 侧走纠错源稿

取代 d959114 的侧面四帧。原稿四帧虽然内容不同，但重复同一条腿在前的姿势，不能作为完整交替步态。

- `side_walk8.png`：最终透明原稿，2行×4列；按行从左到右依次为近脚落地、近脚承重、近脚支撑且远脚抬起、远脚前伸、远脚落地、远脚承重、远脚支撑且近脚抬起、近脚前伸。
- `initial_sheet.png`：第一遍生成稿；其中第3/4/6格的腿部深浅关系不充分，已通过第二次编辑修正，不用它导出。
- `01_generate.txt`、`02_correct_leg_depth.txt`：内置 imagegen 的原始生成与定向纠错提示词。生成时引用的旧 side1.png 是 d959114 版本。
- `regions.json`：实际切片位置与相位。导出共用缩放系数和每行地面基线，不用逐帧脚底归一代替抬落动作。

运行 `python tools/build_c_sprites.py`，输出上层 `side1.png`—`side8.png`；原正背帧及三个站姿保持字节一致。向右由游戏镜像同一套侧走。

运行时侧走16帧/秒，八帧共0.5秒。具体步态核查和原速/慢放预览见 `docs/C侧走纠错_20261026.md`。
