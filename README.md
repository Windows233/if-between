# IF：如果之间（If: Between）

> 一款带 IF 分支选择的像素风剧情 RPG。

接下一桩寻猫委托的事务所主角，在死亡与重来之间发现自己能看见、甚至改写他人脑中的「IF 条件」。为了找回那只猫，她与神秘人做了交易，走进由执念侵蚀现实而成的异界「蚀界」。

---

## 游戏简介

- **类型**：剧情 RPG（俯视角像素地图，室内自由走动，室外点击地图传送）
- **核心机制**：剧情到关键节点会弹出 **IF 选择框**。每个选项对应一种 THEN，多个节点的选择组合起来，演化出不同的后续剧情与结局。
- **篇幅**：两章，7 个结局
  - **第一章 · 猫**：委托、梦境回环、观察他人脑中的 IF、第一次改写条件
  - **第二章 · 蚀界**：废弃学校调查、救援、宵禁追逐、图书馆、背叛与回溯、逃离与交付
- **其他玩法**：救援节奏判定、追逐与 QTE 闪避、物品媒介选择、主动隐蔽

## 运行方式

### 从源码运行

1. 安装 **Godot 4.7.2**（标准版，GDScript，无需 .NET）。
2. 克隆本仓库：
   ```bash
   git clone https://github.com/Windows233/if-between.git
   ```
3. 在 Godot 项目管理器中「导入」仓库根目录下的 `project.godot`。
4. 首次打开时等待资源导入完成，按 **F5** 运行。

> 仓库内含 Godot 编辑器插件 `addons/if_map_editor/`（自制地图编辑器，在编辑器顶部「IF 场景」中打开）。它只在编辑器里加载，不会进入游戏导出包。

## 项目结构

| 路径 | 内容 |
| --- | --- |
| `core/` | 数据层：地图解析、可走判定、条件判定、剧情事件、存档状态 |
| `scenes/` | 运行时：总控、地图绘制与遮挡、演出导演、角色、追逐等玩法 |
| `ui/` | 对话框、IF 选择框、菜单、存档、背包、图鉴等界面 |
| `data/maps/` | 14 张地图数据（JSON，由自制地图编辑器生成） |
| `data/events/` | 32 份剧情事件（节点、分支、选项、演出指令） |
| `data/` 其他 | 物品、结局等配置表 |
| `art/` `audio/` | 美术与音频素材 |
| `addons/if_map_editor/` | 自制 Godot 地图编辑器插件 |
| `tests/` | 自动化测试与真窗口烟测 |
| `tools/` | 数据自查、切图、打包同步等脚本 |
| `docs/` | 开发文档、剧情正本、策划与交接记录 |

剧情与分支以**数据**形式存放在 `data/events/`，策划可以直接改分支，不用改代码。
